# GeoRuTransBot
Перевожу грузинский чат-транслит (латиницу) на русский язык с помощью AI. Быстро, точно и без лишнего текста! 🇬🇪➡️🇷🇺
# Telegram-бот: перевод грузинского транслита на русский

Бот принимает сообщения на грузинском чат-транслите (карто-латиница, например
`Gacnobebt, rom ganaxlda...`) и переводит их на русский язык с помощью Gemini
API (модель `gemini-3.6-flash`).

> **Про модель:** изначально в проекте использовалась `gemini-2.5-flash`, но
> Google закрыла доступ к ней для новых пользователей API — при вызове
> возвращается `404 NOT_FOUND` с рекомендацией переходить на
> `gemini-3.6-flash`. Именно эта модель используется сейчас. Если у вас
> появится похожая ошибка `404 NOT_FOUND` с упоминанием другой модели —
> обновите константу `GEMINI_MODEL` в `main.py` на модель, указанную в тексте
> ошибки (актуальный список моделей: https://ai.google.dev/gemini-api/docs/models).

## Установка

1. Склонируйте/скопируйте проект и перейдите в его директорию.

2. Создайте и активируйте виртуальное окружение (рекомендуется):

   ```bash
   python -m venv venv
   source venv/bin/activate      # Linux / macOS
   venv\Scripts\activate         # Windows
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Скопируйте `.env.example` в `.env` и заполните значения:

   ```bash
   cp .env.example .env
   ```

   ```env
   TELEGRAM_BOT_TOKEN=токен_от_BotFather
   GEMINI_API_KEY=ключ_от_Gemini_API
   ```

   - `TELEGRAM_BOT_TOKEN` — получить у [@BotFather](https://t.me/BotFather) (`/newbot`).
   - `GEMINI_API_KEY` — получить в [Google AI Studio](https://aistudio.google.com/apikey).

## Запуск

```bash
python main.py
```

Бот запустится в режиме long polling. Отправьте ему `/start`, а затем любое
сообщение на грузинском транслите — в ответ придёт перевод на русский.

## Как это работает

1. Пользователь отправляет текстовое сообщение боту.
2. Бот пересылает текст в Gemini (`gemini-3.6-flash`) вместе с системным
   промтом, который просит модель восстановить исходный грузинский текст
   (мхедрули) по латинской транслитерации и перевести его на русский,
   выводя **только** готовый перевод.
3. Бот отправляет полученный перевод пользователю в ответ.

## Обработка ошибок

- Все ошибки при обращении к Gemini API логируются (`logging`, уровень ERROR,
  со стектрейсом) и не приводят к падению бота.
- Пользователь при сбое получает вежливое сообщение об ошибке и может
  повторить попытку.
- При отсутствии `TELEGRAM_BOT_TOKEN` или `GEMINI_API_KEY` бот завершает
  работу при старте с понятным сообщением в логах.

## Заметки

- Модель Gemini вызывается асинхронно (`client.aio.models.generate_content`),
  чтобы не блокировать event loop aiogram.
- Системный промт зашит в `main.py` (константа `SYSTEM_PROMPT`) — его можно
  скорректировать под свои нужды прямо там.
